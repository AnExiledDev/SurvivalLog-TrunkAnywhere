Name: Trunk Anywhere
Summary: Press F6 to open your vehicle's trunk from anywhere before the disaster. Unpaid shop items are kept out of the trunk.

Description (BBCode):
Before the disaster, sorting your trunk means finding the cart and using its organize trunk action. Trunk Anywhere opens the same backpack and trunk view with one key, wherever you are.

[size=5]Main features[/size]
[list]
[*][b]Trunk key[/b]: F6 opens your backpack next to your vehicle's trunk.[/*]
[*][b]Game's own view[/b]: the same trunk view the cart opens, with the game's own checks.[/*]
[*][b]Unpaid items stay out[/b]: you can't drag an unpaid item into the trunk. Pay for it first.[/*]
[*][b]No buying into the trunk[/b]: the shop's trunk tab won't buy. Buy into your bag, then move it.[/*]
[*][b]Take All to Trunk[/b]: when looting with your trunk as a tab, a new button under Take by Type moves everything straight into the trunk. If the trunk fills up, the rest stays where it was.[/*]
[/list]

[size=5]Hotkeys[/size]
[list]
[*][b]F6[/b]: open the backpack and trunk view. Works before the disaster, once you own a vehicle, and only when no other window or storage is open.[/*]
[/list]
The key can be changed in the config.

The mod adds no data of its own to your save. Items you move are moved the same way the game's own trunk view moves them. You can remove it at any time.

[size=5]Known issues[/size]
[list]
[*]Back up your save before trying it for the first time.[/*]
[*]The key does nothing while any other window is open, the settings menu included.[/*]
[*]An unpaid item already in the trunk from before can still be moved or taken out.[/*]
[*]Door boxes are not covered by the unpaid-item check.[/*]
[/list]
If you run into anything strange, please tell me (see Feedback below).

[size=5]Requirements[/size]
[list]

[*][url=https://www.nexusmods.com/survivallog/mods/12]BepInEx for Survival Log[/url]. Install it first.[/*]
[/list]

[size=5]Installation[/size]
[list=1]
[*]Install [url=https://www.nexusmods.com/survivallog/mods/12]BepInEx[/url] [i](if no other mods were installed before, start the game once so BepInEx finishes setup, then quit)[/i].[/*]
[*]Put [font=Courier New]TrunkAnywhere.dll[/font] in the BepInEx&#92;plugins folder inside the game folder. Full path example:
[code]C:&#92;Program Files (x86)&#92;Steam&#92;steamapps&#92;common&#92;Survival Log&#92;BepInEx&#92;plugins&#92;TrunkAnywhere.dll[/code][/*]
[/list]

[size=5]Uninstall[/size]
Delete [font=Courier New]TrunkAnywhere.dll[/font] from the [font=Courier New]BepInEx&#92;plugins[/font] folder.

[size=5]Configuration[/size]
To change the key, edit [font=Courier New]BepInEx&#92;config&#92;com.dev.survivallog.trunkanywhere.cfg[/font] while the game is closed (see [url=https://github.com/AnExiledDev/SurvivalLog-TrunkAnywhere/blob/main/CONFIG.md]CONFIG.md[/url]). Changes apply at the next game start.
